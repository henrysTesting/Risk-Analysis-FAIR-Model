# Gaming Machines & Proprietary Software

Gaming machines and their proprietary software are high-value assets directly tied to Accel Entertainment's revenue and daily operations. Their business model depends on cutting-edge gambling machine software and a platform used to monitor machine performance across thousands of locations.

---

## Threat Vectors

- Unauthorized access
- Hardware/software tampering
- Installation of malware or backdoors
- Theft of proprietary source code

Accel Entertainment is currently in an active hiring push for field technicians, which expands the insider threat surface — properly vetting new technicians is a lengthy process, and oversight may be inconsistent.

---

## Threat Actors

Insider employees, rogue technicians, organized crime syndicates, competitors

---

## Potential Losses

| Threat Method | Threat Actors | Loss Type | Scale |
|---------------|---------------|-----------|-------|
| Unauthorized access / hardware-software tampering | Insiders, rogue technicians, impersonators | Loss of revenue | Medium — machine payout manipulation (case-by-case) |
| Malware / backdoor installation | Insiders, organized crime groups | Operational disruption, persistent system access | Medium-High — malfunctions plus silent data collection |
| Theft of proprietary source code | Competitors, cybercriminals | Loss of proprietary data | High — source code enables zero-day discovery |
| Skimming devices | Criminal groups, insiders | Fines, loss of casino contracts | Low — casinos continuously monitor machines |
